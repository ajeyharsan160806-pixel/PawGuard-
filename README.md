# PawGuard-
### AI-Powered Stray Dog Health Monitoring and Rescue System

## 📌 Project Overview

Paw Guard AI is an intelligent system designed to monitor stray dogs and identify dogs that may be injured, infected or unhealthy.

The system uses image analysis, GPS location tracking and cloud-based monitoring to help animal rescue teams respond quickly.

## 🎯 Objectives

- Detect stray dogs using a camera.
- Analyse dog images using an AI model.
- Identify dogs that may require medical attention.
- Capture GPS location, date and time.
- Upload relevant images to cloud storage.
- Notify rescue teams through a dashboard.

## ⚙️ Key Features

1. AI-based dog health monitoring.
2. GPS location tracking.
3. Image capture and storage.
4. Rescue team notification.
5. Dog monitoring dashboard.
6. Infection statistics and visualizations.

## 🏗️ System Architecture

Camera / Hardware → AI Model → Cloud Database → Web Dashboard → Rescue Team
